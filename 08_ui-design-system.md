# 08 — Unique UI System
**Direction:** "Ledger meets fabric" — warm, tactile, trustworthy; not a generic SaaS look.
**Requirements:**
- Palette: deep indigo ink (#1F2A5A), turmeric accent (#E8A317), cream paper background (#FBF6EA), thread-red for reject (#C8402F), cotton-green for verify (#2E8B57). Define as CSS tokens with light/dark.
- Signature motif: stitched-line dividers (dashed borders), a tape-measure progress bar for lot completion, and a spool-style counter for piece totals.
- Typography: a friendly rounded sans for UI plus a numeric-tabular style for amounts.
- Big touch targets (min 48px), thumb-reach bottom navigation on mobile, number pad with large keys.
- Micro-interactions: satisfying count-up on totals, haptic feedback on verify (where supported), reduced-motion respected.
- Accessibility: contrast AA, labels not colour-only, works at 200% text size.
- Deliver a `/design` route showing all components and states, plus empty states with illustrations.
**Done when:** a first-time tailor can add an entry with no instructions in a usability test of 3 people.
